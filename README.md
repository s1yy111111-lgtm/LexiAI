# LexiAI

LexiAI is an intelligent English vocabulary assistant designed to help users learn and understand English words more efficiently.

## Introduction

LexiAI is a personal open-source project created by a developer who is learning Python, artificial intelligence, and software development.

The purpose of LexiAI is to build a practical and intelligent English learning tool. The project is currently under continuous development and improvement. It starts with basic vocabulary search functions and will gradually integrate AI technologies to provide a smarter learning experience.

In future versions, LexiAI aims to provide:

- AI-powered word explanations
- Intelligent example sentence generation
- Synonym and related word analysis
- Vocabulary learning suggestions
- Personalized English learning assistance

LexiAI is still an evolving project. Everyone is welcome to try it, provide feedback, and participate in making it better.

## Current Features

- English word search
- Word meaning lookup
- Part of speech information
- Vocabulary level information
- Local vocabulary database
